# 门店装修移动端预览

基于 Figma 设计稿还原的 375 × 812 移动端交互页面，使用原生 HTML、CSS 和 JavaScript，无第三方运行依赖。

## 功能

- 外显小图、头图、相册、推荐菜四个 Tab 切换与横向滑动
- 各 Tab 的预览状态与编辑状态
- 图片单选、多选、顺序编号、取消恢复和确认保留
- 相册预览态拖拽排序
- 手机框架、渐变阴影与底部渐变模糊效果
- 独立的内容生成过程动效页面

## 本地预览

直接打开 `index.html`，或在当前目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

内容生成过程动效请打开 `generating.html`。

所有图片与图标均位于 `assets/`，不依赖临时外链。
